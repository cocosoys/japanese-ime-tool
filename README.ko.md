# 일본어 이름 → IME 구문 (japanese-ime-tool)

Windows용 Electron 플로팅 창 도구입니다. 일본어 이름(한자 / 로마자 / 히라가나)을 긁어와 **Microsoft IME(병음)의 "사용자 정의 구문"**에 한 번에 가져오므로, 중국어 IME를 쓰는 중에도 일본어 이름을 빠르게 입력할 수 있습니다.

> 지원 OS: Windows (Microsoft IME의 사용자 정의 구문 파일 `ChsPinyinEUDPv1.lex`에 의존)

## ✨ 기능

- **일본어 이름 수집**: namechef에서 일괄 수집. 성별(여성 / 남성 / 중성)과 스타일(인기 / 독특 / 트렌드)로 필터링하여 배치별로 저장. 상단 카드를 클릭해 필드를 빠르게 전환.
- **세 가지 구문 필드**: 한자(kanji), 로마자(romaji), 히라가나(hiragana) — 언제든 전환.
- **네 가지 바인딩 방식**:
  - **수동**: IME 코드(병음 문자열)를 행마다 입력. 실수 방지를 위해 잠금 가능.
  - **수동(전역)**: 코드를 전역 기본 바인딩에 기록, 배치 간 재사용. 편집·잠금 모두 가능.
  - **QWERTY 키 순서**: `q w e r t y u i o p a s d f g h j k l z x c v b n m`로 자동 배정, 최대 26건.
  - **QWERTY 흐름 순서(qwerFlow)**: 회전 열 `q w e r a s d f z x c v`로 배정, 최대 12건.
- **원클릭 가져오기**: 현재 배치의 앞 N개 이름을 Microsoft IME 사용자 구문에 기록. 가져오기 전 미리보기 표시(화면당 약 10건, 스크롤 가능), "다시 알리지 않음" 옵션 지원.
- **전체 데이터 배치(집계)**: 드롭다운 첫 항목 "전체 데이터 배치"가 모든 배치를 집계합니다. **날짜가 오래된 순으로 소비**(가장 오래된 배치부터 사용)하고, **사용한 데이터는 재사용하지 않음** — 현재 데이터가 가져오기 수에 부족하면 먼저 플레이스홀더 미리보기(부족분은 노란색 "확인 후 생성")를 표시 → 확인 후 **다중 라운드 자동 수집**(실시간 진행 다이얼로그 + 강제 중지 가능) → 완료 후 실제 미리보기를 다시 표시하여 최종 확인.
- **배치 관리**: 드롭다운으로 배치 전환. 펼칠 때마다 자동으로 최신 목록을 다시 읽고, 한 화면에 5개까지 표시(그 이상은 휠 또는 **가는 반투명 세로 스크롤바**로 스크롤). 각 배치에 **녹/적 투톤 진행 막대**(녹색=미사용 / 빨강=사용)로 사용 현황을 실시간 표시. 배치 폴더는 가져온 시각(`년-월-일_시분초_밀리초`, 예: `2026-07-31_114932_1785469772230`)으로 명명됩니다.
- **수동 바인딩 부족 알림**: 수동 모드에서 가져오기 수가 코드 입력 행 수를 초과하면 자동 완성 / 강제 계속 / 취소 대화상자 표시.
- **앱 내 확인 다이얼로그**: "전체 삭제" 같은 위험 작업은 가져오기 미리보기와 동일한 스타일의 앱 내 다이얼로그로 확인("다시 알리지 않음" 체크박스 포함, 영구 저장).
- **상태 표시줄 간소화 + 개발자 모드**: 기본적으로 상태 표시줄은 간결한 결과만 표시(예: "21개 가져옴 → IME 다시 로드됨"). 설정 패널에서 "개발자 모드"를 켜면 전체 진단 정보(파일 경로, 다시 로드 방법 등)가 표시됩니다.
- **설정 패널**: UI 언어(간/번/영/일/한)와 테마(라이트/다크/시스템) 전환, 창 항상 위에 고정, 개발자 모드 전환.
- **로컬 HTTP API**: `127.0.0.1`에 바인딩된 내장 로컬 API 서비스. 설정 패널에서 켜고 끌 수 있으며, 활성화 시 아래에 API 문서 링크(`docs/api-docs.html`)가 표시되어 개발자가 통합하거나 자동화하기 편리합니다.
- **닫기 동작**: 닫기 버튼을 누르면 선택 대화상자(앱 종료 / 트레이로 숨기기)가 표시. "내 선택 기억"을 체크하면 저장되어 다음 실행 시 바로 적용됩니다.
- **설정 영속화**: 언어·테마·구문 필드·바인딩 방식·가져오기 수·고정 상태·API 토글·닫기 동작·마지막으로 연 배치를 `config.yaml`에 저장하고 다음 실행 시 복원.

## 📋 요구 사항

- Windows 10 / 11
- Node.js ≥ 18 (개발 실행용)
- Electron 31 (종속성으로 설치)
- Microsoft IME(병음) 설치 및 활성화

## 🚀 설치 및 실행

```bash
npm install
npm start
# 또는
npm run dev
```

> 참고: 이 도구는 Microsoft IME의 사용자 정의 구문 파일(`ChsPinyinEUDPv1.lex`)에 기록합니다. 가져온 후에는 IME 설정의 "사용자 정의 구문 다시 로드" 또는 IME 재시작으로 변경을 적용하세요.

## 🛠 사용 방법

1. **데이터 수집**: 성별과 스타일을 선택하고 "⚡수집"을 클릭해 배치를 생성·저장.
2. **구문 필드 선택**: 상단 카드(한자 / 로마자 / 히라가나) 또는 드롭다운으로 전환. 현재 카드가 강조표시됩니다.
3. **바인딩 방식 선택**: 수동은 행마다 코드를 입력하고 잠금; qwerty / qwerFlow는 키를 자동 배정.
4. **배치 선택**: "데이터 배치" 드롭다운으로 전환(펼칠 때마다 자동 업데이트). 진행 막대로 각 배치 사용 현황 표시. "전체 데이터 배치"를 선택하면 날짜가 오래된 순으로 모든 배치를 집계하여 소비.
5. **원클릭 가져오기**: 수를 설정하고 "가져오기" 클릭, 미리보기 확인 후 IME에 기록. "전체 데이터 배치"에서 데이터가 부족하면 먼저 플레이스홀더 미리보기(부족분은 노란색 "확인 후 생성") → 확인 후 자동 수집(강제 중지 가능) → 완료 후 실제 미리보기를 다시 표시하여 최종 확인.
6. **되돌리기 / 지우기**: "되돌리기"로 마지막 가져오기 취소. "전체 지우기"는 모든 구문을 비웁니다(앱 내 확인 다이얼로그, "다시 알리지 않음" 지원, 되돌리기 가능).

## ⚙️ 설정 (config.yaml)

`data/config.yaml` 위치:

| 항목 | 설명 | 기본값 |
| --- | --- | --- |
| `gender` | 수집 성별 G/B/U | `G` |
| `popularity` | 수집 스타일 popular/unique/trending | `popular` |
| `phraseField` | 구문 필드 kanji/romaji/hiragana | `kanji` |
| `binding` | 바인딩 방식 manual/manualGlobal/qwerty/qwerFlow | `manual` |
| `count` | 가져오기 수 | `10` |
| `lang` | UI 언어 zh-CN/zh-TW/en/ja/ko | `zh-CN` |
| `theme` | 테마 light/dark/system | `system` |
| `pinned` | 항상 위에 고정 | `false` |
| `lastBatch` | 마지막으로 연 배치 이름(실행 시 복원) | `''` |
| `skipImportPreview` | 가져오기 미리보기 건너뛰기 | `false` |
| `skipClearConfirm` | "전체 지우기" 확인 다이얼로그 건너뛰기 | `false` |
| `skipUsedInSlice` | "일부 데이터 사용됨" 알림 건너뛰기 | `false` |
| `skipOrderAdjust` / `skipOrderOverwrite` | 후보 위치 충돌 조정 / 덮어쓰기 확인 건너뛰기 | `false` |
| `orderMode` | 후보 위치 모드 fixed/auto | `fixed` |
| `orderValue` | 고정 모드 후보 위치 | `1` |
| `apiEnabled` | 로컬 HTTP API 사용 여부 | `true` |
| `apiPort` | 로컬 HTTP API 수신 포트 | `18765` |
| `closeBehavior` | 닫기 버튼 동작: ask=묻기 / close=바로 종료 / minimize=트레이로 숨기기 | `ask` |
| `devMode` | 개발자 모드(상태 표시줄에 전체 진단 정보 표시) | `false` |

## 🔌 로컬 API (개발자용)

`127.0.0.1`에만 바인딩된 내장 로컬 HTTP API. 구문의 가져오기 / 내보내기 / 조회를 스크립트로 처리할 수 있습니다.

- **사용/중지**: 설정 패널의 "로컬 API" 오른쪽의 "사용" 텍스트를 클릭해 전환. 활성화되면 아래에 API 문서 링크가 표시됩니다.
- **영속화**: 켜기/끄기 상태와 포트는 `config.yaml`(`apiEnabled` / `apiPort`)에 기록되어 재시작 후에도 유지됩니다.
- **문서**: 전체 엔드포인트 목록·매개변수·`curl` 예시는 **`docs/api-docs.html`** 참조(설정 패널에서 API를 활성화한 후 문서 링크로 열거나 브라우저에서 파일을 직접 여세요).

> 참고: API는 로컬 루프백 주소에만 바인딩되며 외부 네트워크에 노출되지 않습니다. 신뢰할 수 없는 공유 환경에서는 오래 켜두지 마세요.

## ⚠️ 주의

- Windows + Microsoft IME만 지원. 사용자 정의 구문 파일 형식에 의존.
- 가져온 구문에는 유효한 코드(트리거 코드)가 필요. 빈 코드 항목은 IME 설정에서 편집할 수 없음.
- 수집 기능은 외부 사이트 구조에 의존하며 변경 시 동작하지 않을 수 있음.
- 배치 폴더는 `년-월-일_시분초_밀리초`(예: `2026-07-31_114932_1785469772230`)로 명명. 이전 형식(`년-월-일_시분`)도 계속 인식됩니다.
- 쓰기 시 UDL / EUDP / machxudp 3개 파일을 "코드+구문"으로 일관되게 중복 제거하며 동시에 갱신. 항목 수 불일치로 인한 IME 설정의 "편집 실패"를 방지합니다.
