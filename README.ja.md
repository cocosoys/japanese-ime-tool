# 日本語名 → 入力法フレーズ（japanese-ime-tool）

Windows 向けの Electron フローティングウィンドウ型ツールです。日本語名（漢字 / ローマ字 / ひらがな）を取得し、ワンクリックで**Microsoft IME（ピンイン）の「ユーザー独自の候補」**に取り込み、中国語 IME を使っているときでも日本語名を素早く入力できるようにします。

> 対応 OS：Windows（Microsoft IME のユーザー独自の候補ファイル `ChsPinyinEUDPv1.lex` に依存）

## ✨ 機能

- **日本語名の取得**：namechef から一括取得。性別（女性 / 男性 / 中性）とスタイル（人気 / 個性的 / トレンド）で絞り込み、バッチごとに保存（上部カードをクリックでフィールド切替）。
- **3つのフレーズ項目**：漢字（kanji）、ローマ字（romaji）、ひらがな（hiragana）をいつでも切り替え。
- **4つのバインディング方式**：
  - **手動**：IME コード（ピンイン文字列）を行ごとに入力。誤操作防止にロック可能。
  - **手動（グローバル）**：コードをグローバル既定バインディングに書き込み、バッチ間で再利用。編集・ロックも可能。
  - **QWERTY キー順**：`q w e r t y u i o p a s d f g h j k l z x c v b n m` で自動割り当て、最大 26 件。
  - **QWERTY フロー順（qwerFlow）**：回転系列 `q w e r a s d f z x c v` で割り当て、最大 12 件。
- **ワンクリック取り込み**：現在のバッチの先頭 N 件を Microsoft IME のユーザー候補に書き込み。取り込み前にプレビュー表示（画面約 10 件、スクロール可）、「次回から表示しない」に対応。
- **全データバッチ（集約）**：ドロップダウンの先頭項目「全データバッチ」で全バッチを集約。**日付が古い順に消費**（最も古いバッチから使用）、**使用済みデータは再利用しない**——現在のデータが取り込み件数に足りない場合はプレビューにプレースホルダ（未取得分は黄色の「確定後に生成」）を表示 → 確認後に**複数ラウンドの自動取得**（リアルタイム進捗ダイアログ付き・強制停止可）→ 完了後にもう一度実際のプレビューを表示して最終確認。
- **バッチ管理**：ドロップダウンでバッチ切替。展開のたびに自動で最新リストを再取得し、1 画面に 5 件まで表示（それ以上はホイールまたは**細い半透明の縦スクロールバー**でスクロール）。各バッチに**緑赤ツートン進捗バー**（緑＝未使用 / 赤＝使用済）で使用状況をリアルタイム表示。バッチディレクトリは取得日時（`年-月-日_時分秒_ミリ秒`、例 `2026-07-31_114932_1785469772230`）で命名。
- **手動バインディング不足の通知**：手動モードで取り込み件数がコード入力済み行数を超える場合、自動補完 / 強制続行 / キャンセルのダイアログを表示。
- **アプリ内確認ダイアログ**：「全クリア」などの危険操作は、取り込みプレビューと同じアプリ内ダイアログで確認（「次回から表示しない」チェックボックス付き・永続化）。
- **ステータスバー簡素化 + 開発者モード**：既定では簡潔な結果のみ表示（例「21 件取り込み → IME 再読込済み」）。設定パネルで「開発者モード」を有効にすると完全な診断情報（ファイルパス・再読込方法など）を表示。
- **設定パネル**：UI 言語（簡 / 繁 / 英 / 日 / 韓）とテーマ（ライト / ダーク / システム）の切替、ウィンドウ最前面固定（ピン）、開発者モード切替。
- **ローカル HTTP API**：`127.0.0.1` に束縛された組み込みのローカル API サービス。設定パネルから有効/無効を切り替え可能。有効時はその下に API ドキュメントのリンク（`docs/api-docs.html`）が表示され、開発者の統合や自動化に便利。
- **終了時の動作**：閉じるボタンを押すと選択ダイアログ（アプリを終了 / トレイに隠す）が表示。「選択を記憶」をチェックすると保存され、次回起動時に直接適用。
- **設定の永続化**：言語・テーマ・フレーズ項目・バインディング方式・取り込み件数・ピン状態・API のオンオフ・終了時の動作・最後に開いたバッチを `config.yaml` に保存し、次回起動時に復元。

```bash

```

## 🛠 使い方

1. **データ取得**：性別とスタイルを選び「⚡取得」をクリックし、バッチを生成・保存。
2. **フレーズ項目の選択**：上部のカード（漢字 / ローマ字 / ひらがな）またはドロップダウンで切替。現在のカードがハイライトされます。
3. **バインディング方式の選択**：手動は行ごとにコードを入力してロック；qwerty / qwerFlow はキーを自動割り当て。
4. **バッチの選択**：「データバッチ」ドロップダウンで切替（展開のたびに自動更新）。進捗バーで各バッチの使用状況を表示。「全データバッチ」を選ぶと日付の古い順に全バッチを集約して消費。
5. **ワンクリック取り込み**：件数を設定し「取り込み」をクリック、プレビューを確認して IME に書き込み。「全データバッチ」でデータ不足の場合は、まずプレースホルダ付きプレビュー（未取得分は黄色の「確定後に生成」）→ 確認後に自動取得（強制停止可）→ 完了後にもう一度実際のプレビューを表示して最終確認。
6. **取り消し / クリア**：「取り消し」で直前の取り込みを元に戻せます。「すべてクリア」は全候補を空にします（アプリ内確認ダイアログ、「次回から表示しない」対応、取り消し可）。

## ⚙️ 設定（config.yaml）

`data/config.yaml` に配置：

| 項目 | 説明 | 既定値 |
| --- | --- | --- |
| `gender` | 取得性別 G/B/U | `G` |
| `popularity` | 取得スタイル popular/unique/trending | `popular` |
| `phraseField` | フレーズ項目 kanji/romaji/hiragana | `kanji` |
| `binding` | バインディング方式 manual/manualGlobal/qwerty/qwerFlow | `manual` |
| `count` | 取り込み件数 | `10` |
| `lang` | UI 言語 zh-CN/zh-TW/en/ja/ko | `zh-CN` |
| `theme` | テーマ light/dark/system | `system` |
| `pinned` | 最前面固定 | `false` |
| `lastBatch` | 最後に開いたバッチ名（起動時に復元） | `''` |
| `skipImportPreview` | 取り込みプレビューを省略 | `false` |
| `skipClearConfirm` | 「全クリア」確認ダイアログを省略 | `false` |
| `skipUsedInSlice` | 「一部データ使用済み」の通知を省略 | `false` |
| `skipOrderAdjust` / `skipOrderOverwrite` | 候補位置の衝突調整 / 上書き確認を省略 | `false` |
| `orderMode` | 候補位置モード fixed/auto | `fixed` |
| `orderValue` | 固定モードの候補位置 | `1` |
| `apiEnabled` | ローカル HTTP API の有効/無効 | `true` |
| `apiPort` | ローカル HTTP API の待ち受けポート | `18765` |
| `closeBehavior` | 閉じるボタンの動作：ask=確認 / close=直接終了 / minimize=トレイに隠す | `ask` |
| `devMode` | 開発者モード（ステータスバーに完全な診断情報を表示） | `false` |

## 🔌 ローカル API（開発者向け）

`127.0.0.1` のみに束縛された組み込みのローカル HTTP API。フレーズの取り込み / 出力 / 検索をスクリプトから操作できます。

- **有効 / 無効**：設定パネルの「ローカル API」右側の「有効」文字をクリックで切り替え。有効時はその下に API ドキュメントのリンクが表示されます。
- **永続化**：オンオフ状態とポートは `config.yaml`（`apiEnabled` / `apiPort`）に書き込まれ、再起動後も維持されます。
- **ドキュメント**：エンドポイント一覧・パラメータ・`curl` 例は **`docs/api-docs.html`** を参照（設定パネルで API を有効にした後、ドキュメントリンクから開くか、ブラウザで直接ファイルを開いてください）。

> 注意：API はローカルのループバックアドレスのみに束縛され、外部ネットワークには公開されません。信頼できない共有環境では長時間有効にしないでください。

## ⚠️ 注意

- Windows + Microsoft IME のみ対応。ユーザー独自の候補ファイル形式に依存します。
- 取り込むフレーズには有効なコード（トリガーコード）が必要です。空コードの項目は IME 設定で編集できません。
- 取得機能はサードパーティサイトの構造に依存し、変更で動作しなくなる場合があります。
- バッチディレクトリは `年-月-日_時分秒_ミリ秒`（例 `2026-07-31_114932_1785469772230`）で命名。旧形式（`年-月-日_時分`）も引き続き認識されます。
- 書き込み時は UDL / EUDP / machxudp の 3 ファイルを「コード+フレーズ」で一貫して重複排除しつつ同時に更新。エントリ数不一致による IME 設定の「編集失敗」を防ぎます。
