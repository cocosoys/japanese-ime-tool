# 日文名 → 輸入法短語（japanese-ime-tool）

一個 Windows 平台的 Electron 懸浮窗小工具：擷取日文名（漢字 / 羅馬音 / 平假名），並將其一鍵匯入 **微軟拼音輸入法**的「使用者自訂短語」，讓你在中文輸入法下也能快速打出日文名。

> 適用系統：Windows（依賴微軟拼音的使用者自訂短語檔 `ChsPinyinEUDPv1.lex`）。

## ✨ 功能特性

- **擷取日文名**：從 namechef 擷取一批日文名，支援依性別（女名 / 男名 / 中性）與風格（熱門 / 獨特 / 流行）篩選，依批次儲存到本機；點擊頂部儀表卡可快速切換欄位。
- **三種短語欄位**：漢字（kanji）、羅馬音（romaji）、平假名（hiragana），可隨時切換。
- **四種綁定方式**：
  - **手動**：逐行填寫輸入法編碼（拼音串），可鎖定防止誤改。
  - **手動（全域）**：編碼寫入全域預設綁定，跨批次複用，同樣可編輯與鎖定。
  - **英文鍵位順序（qwerty）**：自動依 `q w e r t y u i o p a s d f g h j k l z x c v b n m` 分配，最多 26 條。
  - **英文鍵位流轉順序（qwerFlow）**：依 `q w e r a s d f z x c v` 流轉分配，最多 12 條。
- **一鍵匯入**：把目前批次前 N 條名字寫入微軟拼音使用者自訂短語，匯入前彈出預覽（每屏約 10 條，可捲動），支援「此後不再提醒」。
- **所有資料批次（聚合）**：下拉首項「所有資料批次」聚合全部批次；**依日期從早到晚消耗**（最早批次先使用），且**不復用已使用資料**——目前資料量不足匯入數量時，會先彈出佔位預覽（黃色「確認後生成」）→ 確認後**多輪擷取補足**（帶即時進度彈窗，可強制停止）→ 完成後再次預覽真實條目供二次確認。
- **資料批次管理**：下拉切換批次，每次展開自動讀取最新批次列表；列表一屏顯示 5 個批次，超出部分透過滾輪或右側**細半透明垂直滑動條**捲動；每個批次右側有**綠紅雙色進度條**（綠 = 未使用 / 紅 = 已使用）即時顯示使用情況。批次目錄依抓取時間命名（`年-月-日_時分秒_毫秒`，如 `2026-07-31_114932_1785469772230`）。
- **手動綁定不足提示**：手動模式下若匯入數量大於已填寫編碼行數，彈窗讓你選擇自動補全 / 強制繼續 / 取消。
- **應用內確認彈窗**：「一鍵清除」等危險操作使用與匯入預覽同款應用內彈窗確認（含「此後不再提醒」，勾選後持久化）。
- **狀態列精簡 + 開發者模式**：預設狀態列只顯示精簡結果（如「已匯入 21 條 → IME 已重載」）；在設定面板開啟「開發者模式」後顯示完整診斷資訊（檔案路徑、重載方法等）。
- **設定面板**：切換介面語言（簡 / 繁 / 英 / 日 / 韓）與主題（亮 / 暗 / 跟隨系統）；固定視窗到最前（置頂）；開發者模式開關。
- **本地 HTTP API**：內建本地 API 服務（繫結 `127.0.0.1`），可在設定面板啟停；啟用時下方顯示 API 文件位址（`docs/api-docs.html`），便於開發者整合與自動化。
- **關閉行為**：點擊關閉按鈕彈出選擇（關閉應用 / 隱藏到托盤），可勾選「記住我的選擇」將選擇持久化，下次啟動直接生效。
- **設定持久化**：語言、主題、短語欄位、綁定方式、匯入數量、置頂狀態、API 開關、關閉行為、上次開啟的批次等均記入 `config.yaml`，下次啟動自動復原。

## 📋 環境要求

- Windows 10 / 11
- Node.js ≥ 18（開發執行用）
- Electron 31（作為依賴安裝）
- 已安裝並啟用**微軟拼音輸入法**

## 🚀 安裝與執行

```bash
npm install
npm start
# 或
npm run dev
```

> 說明：本工具透過寫入微軟拼音的自訂短語檔（`ChsPinyinEUDPv1.lex`）運作，匯入後需在輸入法設定中「重新載入使用者自訂短語」或重新啟動輸入法使變更生效。

## 🛠 使用說明

1. **擷取資料**：選擇性別與風格，點擊「⚡擷取」，生成並儲存一個資料批次。
2. **選擇短語欄位**：點擊頂部儀表卡（漢字 / 羅馬音 / 平假名）或下拉框切換；儀表卡會高亮目前欄位。
3. **選擇綁定方式**：手動模式逐行填編碼並鎖定；qwerty / qwerFlow 自動分配鍵位。
4. **選擇資料批次**：透過「資料批次」下拉框切換（每次展開自動重新整理）；進度條顯示各批次使用情況；選擇「所有資料批次」則依日期從早到晚聚合消耗全部批次。
5. **一鍵匯入**：設定匯入數量，點擊「一鍵匯入」，預覽確認後寫入輸入法。若「所有資料批次」資料不足，會先顯示佔位預覽（缺少條目為黃色「確認後生成」），確認後自動多輪擷取補足（可強制停止），擷取完成後再彈最終預覽供二次確認。
6. **撤回 / 清除**：「撤回」可撤銷上一次匯入；「一鍵清除」清空全部自訂短語（應用內確認彈窗，可勾選「此後不再提醒」，可撤回復原）。

## ⚙️ 設定（config.yaml）

設定檔位於 `data/config.yaml`，支援的欄位：

| 欄位 | 說明 | 預設值 |
| --- | --- | --- |
| `gender` | 擷取性別 G/B/U | `G` |
| `popularity` | 擷取風格 popular/unique/trending | `popular` |
| `phraseField` | 短語欄位 kanji/romaji/hiragana | `kanji` |
| `binding` | 綁定方式 manual/manualGlobal/qwerty/qwerFlow | `manual` |
| `count` | 匯入數量 | `10` |
| `lang` | 介面語言 zh-CN/zh-TW/en/ja/ko | `zh-CN` |
| `theme` | 主題 light/dark/system | `system` |
| `pinned` | 是否置頂 | `false` |
| `lastBatch` | 上次開啟的資料批次名（啟動自動復原） | `''` |
| `skipImportPreview` | 是否跳過匯入預覽 | `false` |
| `skipClearConfirm` | 是否跳過「一鍵清除」確認彈窗 | `false` |
| `skipUsedInSlice` | 是否跳過「部分資料已使用」提示 | `false` |
| `skipOrderAdjust` / `skipOrderOverwrite` | 是否跳過候選位置衝突調整 / 覆蓋確認 | `false` |
| `orderMode` | 候選位置模式 fixed/auto | `fixed` |
| `orderValue` | 固定模式候選位置 | `1` |
| `apiEnabled` | 本地 HTTP API 是否啟用 | `true` |
| `apiPort` | 本地 HTTP API 監聽連接埠 | `18765` |
| `closeBehavior` | 關閉按鈕行為：ask=詢問 / close=直接關閉 / minimize=隱藏到托盤 | `ask` |
| `devMode` | 開發者模式（狀態列顯示完整診斷資訊） | `false` |

## 🔌 本地 API（開發者）

內建一個僅繫結 `127.0.0.1` 的本地 HTTP API，用於腳本化匯入 / 匯出 / 查詢短語。

- **啟用 / 停用**：設定面板「本地 API」右側的「已啟用」文字可一鍵啟停；啟用狀態下其下方顯示 API 文件位址。
- **持久化**：開關狀態與連接埠寫入 `config.yaml`（`apiEnabled` / `apiPort`），重啟後保留。
- **文件**：完整端點清單、參數與 `curl` 範例見 **`docs/api-docs.html`**（在設定面板啟用 API 後點擊文件連結即可開啟，或直接在瀏覽器開啟該檔案）。

> 注意：API 僅繫結本機回環位址，不對外網暴露；請勿在不可信的共用環境下長期開啟。

## ⚠️ 注意事項

- 僅支援 Windows + 微軟拼音輸入法，依賴使用者自訂短語檔格式。
- 匯入的短語需帶有效編碼（觸發碼）；空編碼的條目無法在輸入法設定中編輯。
- 擷取功能依賴第三方網站結構，可能隨對方改版失效，請留意更新。
- 批次目錄依 `年-月-日_時分秒_毫秒` 命名（如 `2026-07-31_114932_1785469772230`）；歷史舊格式目錄（`年-月-日_時分`）仍被相容識別。
- 寫入時同時維護 UDL / EUDP / machxudp 三個檔案且依「編碼+短語」一致去重，避免因三方條目數不一致導致輸入法設定中「編輯失敗」。
