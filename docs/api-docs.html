Overview / 概述
本地 HTTP API 服务提供 RESTful 风格的网络接口，供本地脚本或外部程序以 HTTP 方式调用工具各项功能。 服务仅绑定 127.0.0.1（本机回环），不对外暴露。所有请求/响应均为 JSON 格式。 成功响应统一为 { ok: true, data: ... }，失败为 { ok: false, error: "..." }。 端口可在 config.yaml 中通过 apiPort 配置（默认 18765），通过 apiEnabled 控制启停。

POST /api/fetch 抓取日文名并存入新批次 ▸
从 namechef.co 抓取一批日文名并保存到新的数据批次。支持三种模式：
① 直接 HTML — 传入完整页面 HTML（跳过网络请求）；
② Cookie 模式 — 传入 cf_clearance cookie 进行 fetch；
③ 全自动模式 — 无 cookie 时自动弹出隐藏窗口通过 Cloudflare 质询。

操作完成后会自动通知渲染进程刷新界面。
Request Body
FieldTypeRequiredDescription

popularitystringNo名字风格：popular / unique / trending，默认 popular
cookiestringNocf_clearance cookie 值（有此值时跳过自动质询）
htmlstringNo完整页面 HTML（优先级最高，>500 字符时直接解析）
urlstringNo目标 URL（全自动模式使用，默认 namechef 日文名生成器）
Response Fields
FieldTypeDescription
countnumber抓取到的名字数量
batchstring | null新建的批次目录名
entriesArray<Object>名字条目详细数据（kanji/romaji/hiragana/raw 等）

POST /api/fetch
Content-Type: application/json
{ "gender": "G", "popularity": "popular" }

// Response
{

  "data": {
    "count": 21,

      { "kanji": "小川梨恵", "romaji": "Rie Ogawa", "hiragana": "りお おがわ", "raw": "小川梨恵" },

Quick Examples / 快速示例
以下示例使用 curl（需替换端口号）：
# 1. 健康检查
curl http://127.0.0.1:18765/api/health

# 2. 获取所有批次
curl http://127.0.0.1:18765/api/batches

# 3. 抓取日文名（全自动过 CF）
curl -X POST http://127.0.0.1:18765/api/fetch \
  -H "Content-Type: application/json" \
  -d '{"gender":"G","popularity":"popular"}'

# 4. 导入前 10 条（QWERTY 绑定）
curl -X POST http://127.0.0.1:18765/api/import \
  -H "Content-Type: application/json" \
  -d '{"batch":"2026-07-31_114932_1785469772230","count":10,"binding":"qwerty"}'

# 5. 添加单条短语
curl -X POST http://127.0.0.1:18765/api/phrase \
  -H "Content-Type: application/json" \
  -d '{"code":"test","word":"テスト","order":1}'

# 6. 删除单条短语
curl -X POST http://127.0.0.1:18765/api/phrase/delete \
  -H "Content-Type: application/json" \
  -d '{"code":"test","word":"テスト"}'

# 7. 清空所有短语
curl -X POST http://127.0.0.1:18765/api/clear

# 8. 撤回
curl -X POST http://127.0.0.1:18765/api/undo \
  -H "Content-Type: application/json" -d '{}'
